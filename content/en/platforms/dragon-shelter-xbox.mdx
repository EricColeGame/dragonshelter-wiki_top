## Controller Setup and Accessibility Best Practices

When transitioning complex management interfaces from keyboard and mouse to console gamepads, user interface layout makes or breaks the experience. In games featuring extensive inventory management, submenus, and tool wheels, intuitive button mapping is critical.

Developers working on console ports must prioritize smooth analog cursor navigation, clear snap-to-grid options for farm placement, and remappable triggers. 

### Suggested Gamepad Mapping for Console Players

* **Left Stick:** Character Movement / Movement navigation in menus
* **Right Stick:** Camera orbit / Precision placement targeting
* **Right Trigger (RT):** Primary tool action (hoe, watering bucket, brush)
* **Left Trigger (LT):** Dragon command radial menu
* **Right Bumper (RB) / Left Bumper (LB):** Quick-swap hotbar items
* **A Button:** Interact, gather, confirm menu choice
* **B Button:** Cancel, sprint, mount/dismount larger dragons
* **X Button:** Feed companion, open personal satchel
* **Y Button:** Dragon status, bond stats, grooming overview
* **D-Pad:** Direct whistle commands (Call Companion, Stay, Return to Shelter)

By refining these control inputs, a future console edition will feel purposeful and responsive rather than like a hurried computer port.
