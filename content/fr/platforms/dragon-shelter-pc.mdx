## Résolution des problèmes fréquents d'affichage et de performances sur PC

Même les titres indépendants les plus soignés peuvent rencontrer des écueils techniques mineurs sur certaines configurations matérielles. Faire tourner le logiciel **dragon shelter pc** sur différentes versions de pilotes graphiques et divers formats d'écran nécessite parfois quelques ajustements rapides.

Les données de dépannage de la communauté mettent en lumière plusieurs problèmes de configuration récurrents pouvant être résolus en quelques minutes grâce aux procédures de maintenance habituelles de Windows.

| Problème rencontré | Cause probable | Solution recommandée |
| :--- | :--- | :--- |
| **Micro-saccades lors des transitions de zone** | Goulet d'étranglement du streaming de textures lié à un disque dur mécanique | Déplacez les fichiers du jeu sur un SSD ; assurez-vous que le fichier d'échange (pagefile) de Windows est géré automatiquement |
| **Commandes de la manette non reconnues** | Conflit entre Steam Input et un logiciel tiers de remappage de manette | Désactivez les remappeurs externes ; activez la configuration générique de manette dans les paramètres du client |
| **Déchirement d'écran (tearing) malgré un framerate élevé** | Inadéquation du taux de rafraîchissement entre le jeu et l'écran de bureau | Vérifiez le taux de rafraîchissement dans les Paramètres d'affichage de Windows ; activez FreeSync / G-Sync |
| **Écran noir au lancement** | Pilotes graphiques obsolètes ou packages Visual C++ Redistributable manquants | Mettez à jour les pilotes GPU ; vérifiez l'intégrité des fichiers du jeu via votre lanceur de bureau |
| **Bandes noires en ultra-large (21:9 / 32:9)** | Verrouillage du format d'affichage sur certains éléments d'interface et cinématiques | Passez en mode Fenêtré sans bordure ; vérifiez la résolution native dans l'onglet d'affichage |

L'expérience des joueurs indique que l'exécution de superpositions d'enregistrement en arrière-plan peut parfois provoquer de brusques baisses de framerate lors de séquences chargées en particules. Désactiver les captures en arrière-plan superflues apporte un gain immédiat de stabilité si votre matériel se situe près de la configuration minimale.

Oui, le jeu est bien optimisé pour les configurations d'entrée de gamme.
